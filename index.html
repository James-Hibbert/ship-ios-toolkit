The pipeline, honestly explained

Apple's tools only run on macOS — but they don't have to run on your machine. Here's the whole approach, free. The toolkit gives you every config file, gotcha and fix to execute it in an afternoon instead of three months of forum archaeology.

  1. Apple Developer account + App Store Connect API key

    One key replaces every "log into Xcode" step. Your cloud builder authenticates as you.

  2. A cloud Mac builds your app

    A CI service (Codemagic) rents you a Mac for the minutes each build takes. Free tier covers ~20 builds a month.

  3. Code signing with zero Xcode

    Certificates and provisioning profiles generated automatically from your API key. No OpenSSL rituals on Windows.

  4. Every Xcode GUI task becomes a text file

    Bundle IDs, deployment targets, permissions, icons — all set in pbxproj, Podfile, Info.plist and pubspec.yaml from your editor.

  5. Push to Git → signed .ipa lands on TestFlight

    Test on one real iPhone via TestFlight. You never touch the build machine.

  6. Survive App Review

    Most first submissions get rejected for the same five reasons. Clear them before you submit, not after.
